# diplom_project_XYZ

## О проекте

**diplom_project_XYZ** — 2D-игра, разработанная на C++ с использованием библиотеки SFML и собственного игрового движка `XYZEngine`.

Проект реализован в стиле аркады/roguelike и включает:

* систему игровых состояний (меню, игровой процесс, победа, поражение);
* объекты игры (игрок, окружение, врги, босс);
* обработку коллизий;
* уровни и генерацию игровых объектов;
* систему рендера и управление сценой.

Основная цель проекта — продемонстрировать архитектуру игрового движка, работу с объектно-ориентированным программированием и создание полноценной игры на C++.

## Как запустить проект

### 1. Клонировать репозиторий

```bash
git clone https://github.com/vycheslavg/diplom_project_XYZ.git
```

### 2. Открыть проект

Откройте файл:

```bash
Game.sln
```

в **Visual Studio**.

### 3. Проверить библиотеки SFML

Библиотеки SFML уже находятся в проекте и распакованы.
При необходимости убедитесь, что пути к `include` и `lib` корректно указаны в настройках Visual Studio.

### 4. Сборка и запуск

* Выберите конфигурацию `Debug` или `Release`.
* Нажмите `Start` / `F5`.
